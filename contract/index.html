Four verbs and a capacity answer

The Native Station Contract is the versioned, protocol-neutral BadTower service contract: Reserve, Submit, Claim, Settle, health, capacity, and graceful shutdown. It is directly usable with no protocol plugin.

Reserve — one opaque Station Address

Reserve allocates or renews one opaque Station Address inside a Station Namespace: an opaque, bounded-lifetime destination token that is not an endpoint identity, agent address, or proof of ownership. The caller supplies a request identifier and a lifetime; identifiers must match the native ID patterns enforced by the contract.

Submit — opaque Transport Units under expiry and idempotency

Submit stores one opaque Transport Unit for a Station Address under explicit expiry and idempotency. A Transport Unit is opaque bytes plus fixed native metadata for unit identity, destination, expiry, size, idempotency, and bounded carriage; the Core never interprets the bytes. In the Go implementation, submission writes the immutable payload and its mutable delivery metadata exactly once in one synchronous atomic batch.

Claim — a bounded ordered batch

Claim takes a bounded, ordered batch of eligible Transport Units under an expiring Delivery Claim. A Delivery Claim is time- and count-bounded and bound to a monotonic ownership epoch, so stale work cannot commit after transfer or restart. In BadTower.js the same idea is simpler: delivery is at-least-once with a 16-packet in-flight window, and claimed-but-unsettled packets replay in sequence order on the next claim — the caller passes its in-flight sequences as an exclude list.

Settle — complete or release

Settle is an idempotent native instruction to complete or release currently claimed Transport Units, producing a deterministic Settlement Record. In BadTower.js, settle deletes the stored packets; revocation deletes everything and makes the mailbox unable to bind again.

The two implementations disagree on expiry: the Go contract submits units under explicit expiry and reclaims expired state incrementally, while BadTower.js stores undelivered packets permanently — a stored packet leaves only on the recipient's settle or on revocation.

Health, capacity, and shutdown

The contract also owns bounded health, capacity, and graceful-shutdown behavior. The Go Station answers standard grpc.health.v1 probes and GetCapacity; readiness falls before drain, new Reserve/Submit/Claim calls stop during drain, and Settle remains available for a bounded window. BadTower.js exposes an unauthenticated /healthz liveness route and a GET /v1/native/capacity endpoint returning capacity and stored-byte counts.

The BadTower.js native HTTP binding

BadTower.js serves the contract over HTTPS at fixed paths with a bearer admission credential:

Authorization: Bearer btm1.<…>
          POST /v1/native/reserve   — bind the mailbox to one opaque subject
          POST /v1/native/submit    — handle(32) ‖ packet, routes by the handle
          POST /v1/native/claim     — replay ordered units, excluding in-flight
          POST /v1/native/settle    — delete settled packets
          GET  /v1/native/capacity  — capacityBytes ‖ databaseBytes
          POST /v1/revoke           — offline-HMAC revocation, idempotent
          GET  /healthz             — unauthenticated liveness

Bodies are application/octet-stream; no response carries error text. The Go binding is gRPC service badtower.station.v1.Station over TLS 1.3 with ALPN h2, or a mode-0600 Unix socket, with bearer credentials on every data-plane RPC.

Failure semantics

The native candidate fails closed on invalid configuration, retired data roots, unknown store identity, authentication failure, malformed IDs, quota and capacity exhaustion, stale claim epochs, expired addresses and units, clock-unsafe conditions, and overload. Failures map to the closed StationFailure taxonomy and the gRPC status codes defined by the native contract; an unknown service or version returns UNIMPLEMENTED. In BadTower.js, submit outcomes are explicit: accepted, rejected, or transient, with a small fixed set of reason classes.
