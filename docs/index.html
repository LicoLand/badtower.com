BadTower is one pure, protocol-neutral communication Station. It moves opaque Transport Units between endpoints and stays untrusted by design.

Four verbs. One contract.

The Native Station Contract works with no protocol plugin and carries no external protocol semantics. It also owns bounded health, capacity, and graceful shutdown.

  1. Reserve

    Reserve or renew one opaque Station Address.

  2. Submit

    Submit one opaque Transport Unit under explicit expiry and idempotency.

  3. Claim

    Claim a bounded, ordered batch under an expiring Delivery Claim.

  4. Settle

    Settle claimed units with deterministic complete or release behavior.

The Native Station Contract

Bad by design.

A Station is untrusted infrastructure. Every endpoint treats its signals according to its own trust model.

Why you should not trust the tower

A Station Signal never proves

  • peer identity
  • authenticity
  • integrity
  • freshness
  • replay rejection
  • user approval
  • endpoint receipt
  • task completion
  • tool effect
  • business acknowledgement

Built from the ground up, in order.

Later stages cannot repair or redefine unfinished native behavior, and a plugin is never a prerequisite for the stages before it.

  1. Station Core

    The protocol-neutral core and its native contract.

  2. Station Instance

    One standalone, durable, recoverable, packaged, observable Station.

  3. Station Cluster

    The same native contract across replaceable members.

  4. Extension contract

    A separately packaged boundary for external processes.

  5. Protocol plugins

    Explicitly selected, independent, absent by default.

Where each stage stands today

Protocols stay outside the tower.

LicoArc, A2A, ACP, and MCP are optional external plugin plans, not Core features. Each plugin is its own process with its own listener, state, budget, and release. The Core never discovers, loads, embeds, or supervises one.
