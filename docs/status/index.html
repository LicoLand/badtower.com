Verification

Focused race tests verify the deterministic native command machine, partition placement, quorum failure, restart/catch-up, snapshots, mTLS peer admission, membership changes, interrupted rebalance recovery, distributed backup/restore, upgrade preflight, and the Core import firewall. The repository build, ordinary race suite, vet suite, and focused four-node Cluster lifecycle gate pass.

The exact Station Instance load gate was exercised but remains below its required 3,000 terminal units/s; the formal Instance soak and Cluster load/soak runs are not recorded as accepted. Consequently Native Excellence and downstream production admission remain open.

The signed standard node package is an implemented and locally verified candidate for the planned 0.2.0 line. No public package, source tag, release signature, or governed channel publication is claimed; no named hosted Station, Cluster, plugin, or network is claimed operating.

Support

The native Station Contract badtower.station.v1 is implemented in source as a candidate only: it has no current publication, compatibility, or hosted support claim. The removed integrated HTTP relay path is unsupported, and Station Core, the completed Station Instance, the Station Cluster, the External Extension Contract, and every protocol plugin have no current support claim. A protocol release elsewhere never promotes BadTower support automatically.

BadTower.js

BadTower.js is in pre-1.0 preview. The native contract and the licoarc.mailbox.v1 wire grammar are documented in its API reference; conformance runs through npm run check and the test suite covering mailbox, composition, native, station, and boundary tests. The core is verifiable without the plugin through a core-only synthetic station harness.

Implementation in source does not establish verification, release, support, or operation.
