# Website assets

- `fonts/bricolage-grotesque.woff2` is Bricolage Grotesque, sourced from Google
  Fonts. Its SIL Open Font License is in `fonts/OFL-Bricolage-Grotesque.txt`.
- `/net.js` draws the field of towers and is owned by this repository.
- `/site.js` owns the page's motion state and the look of the field.
- `/favicon.svg` is a gold tower on a black tile.

All served assets are local to this site.
